# Python Reference Pipeline

`paint_by_numbers.py` ist die Python-Referenzpipeline und bleibt die wichtigste
algorithmische Vergleichsbasis fuer Paritaet und finale Qualitaetsfragen.

Die zugehoerigen Referenzartefakte liegen in `output/`. Neue temporaere oder grosse
Experimentausgaben sollten nicht ungeprueft versioniert werden.
